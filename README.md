# 音准可视化 · Pitch Scope

一个只做一件事的本地小工具：**采集麦克风或系统播放的单声部音频，实时显示音名 / 八度 / 音分偏差，并画出一条“时间–音高”曲线。**

它面向个人唱歌练习——唱一个音，看一眼曲线有没有飘、偏高还是偏低；也可以把视频、游戏里的单声部旋律接进来做同样的观察。

> 音频只在浏览器内存里处理，不上传、不联网、不写文件。

---

## 1. 它做什么 / 不做什么

**做：**

- 麦克风输入、设备选择、输入电平显示、麦克风权限提示
- 系统声音输入（浏览器共享屏幕时勾选“分享系统音频”），可用于视频、游戏、播放器
- 单声部基频估计（YIN），默认检测范围 C2–C6
- 十二平均律映射：音名 + 八度 + 音分偏差 + 置信度
- 实时“时间–音高”曲线，纵轴是 CDEFGAB 音名，低置信度区间自动断开
- 目标音参考线（无 / C4 / D4 / E4 / G4 / A4），只做视觉参考
- A4 参考频率可配置（默认 440 Hz，范围 415–466 Hz）
- “信号不足 / 检测中 / 低置信度 / 超出范围 / 输入过载 / 音频中断”状态提示

**不做（有意为之，不是没做完）：**

- 不打分、不评等级、不算命中率、不算平均偏差
- 不生成练习报告、不排行、不做唱功评价
- 不评价音色、气息、节奏、情感，不做唱法诊断
- 不做复音 / 和弦 / 多人同时演唱
- 不做全频段频谱分析，频谱不是主界面
- 不录音、不导出、不上传

## 4. 麦克风 / 系统声音权限

### 4.1 麦克风

1. 控制条“音频来源”保持 **麦克风**。
2. 点击左下角 **“开始检测”**。
3. 浏览器第一次会弹窗询问麦克风权限，选择 **允许**。
4. 如果误点了拒绝：
   - Chrome：点击地址栏左侧的站点图标 → “网站设置” → 麦克风 → 允许 → 刷新页面。
   - Edge：地址栏左侧图标 → “权限” → 麦克风 → 允许。
5. 如果系统层面也禁止了麦克风：Windows 设置 → 隐私和安全性 → 麦克风 → 允许桌面应用访问麦克风。

### 4.2 系统声音

1. 控制条“音频来源”选择 **系统声音**。此时“输入设备”会变成“共享源”，不能选具体设备。
2. 点击 **“开始检测”**，浏览器会弹出共享窗口。
3. 选择 **“整个屏幕”**，并勾选窗口底部的 **“分享系统音频”**（部分版本叫 “Share system audio”）。
4. 点“共享”。界面开始显示输入电平和音高曲线。
5. 如果没有勾选音频，界面会提示“这次共享没有包含音频”，不会误报音名。

系统声音是通过浏览器的屏幕共享实现的：共享期间浏览器会显示“正在共享屏幕”的提示。**视频轨只用于维持共享会话，不绘制、不上传；关闭检测或点“停止共享”即结束。** 建议在练习时只共享必要的屏幕，避免把聊天窗口、密码等敏感内容放在共享范围内。

点击“开始检测”后，按钮会变成“停止检测”；状态从“未启动”变成“检测中”或“信号不足”。

## 5. 界面怎么读

```
┌ 当前音高 ────────────────┐   ┌ 即时音高 ───────────────────────┐
│                         │   │  C6 ┤                            │
│          D4             │   │  C5 ┤      ╭─╮                   │
│   稳定单音 · 置信度 86%  │   │  C4 ┤  ╭───╯ ╰──╮                │
│                         │   │  C3 ┤──╯        ╰─╮              │
│  +12 cents  相对 D4     │   │  C2 ┤            ╰──             │
│  ├───────●───────┤       │   │     └──────────────────────    │
│  偏低      准      偏高  │   │      −15  −10  −5   0   （秒）    │
│                         │   └──────────────────────────────────┘
│  输入电平 ███████░░░     │
│  −70      门限 −60   0   │
└─────────────────────────┘
```

| 元素 | 含义 |
| --- | --- |
| 大号字母 + 数字 | 最近音名与八度，例如 `D4` |
| `+12 cents` | 相对最近音名的音分偏差；正=偏高，负=偏低 |
| 中央音分条 | 左偏低、中为准、右偏高；±5 cents 是绿色“准”区 |
| 输入电平 | 当前 RMS 电平；红色竖线是门限 |
| 音高曲线 | 横轴最近 10/15/30 秒，纵轴 CDEFGAB 音名 |
| 虚线 | 目标音参考线，上下浅色带是 ±50 cents |
| 曲线断开 | 该段时间内低置信度 / 无声，没有稳定音高 |

控制条左下角可以切换 **音频来源：麦克风 / 系统声音**。选“系统声音”后，开始检测时会要求共享屏幕并勾选分享音频。

状态说明：

| 状态 | 含义 | 界面表现 |
| --- | --- | --- |
| 未启动 | 还没点开始 | 大号 `—`，空曲线 |
| 检测中 | 有稳定单音 | 显示音名、音分、连续曲线 |
| 信号不足 | 电平低于门限，或没有声音 | 不显示音名，曲线断开 |
| 低置信度 | 有声音但不像稳定单音（噪声、气声、复音） | 不画确定音高点，曲线断开 |
| 超出范围 | 基频在设定音域之外 | 显示“超出范围”，不出音名 |
| 输入过载 | 削波比例过高 | 提示降低音量 / 远离麦克风 |
| 音频中断 | 1.5 秒没有收到音频帧 | 提示检查输入设备 |
| 不可用 | 权限被拒、设备被占用等 | 顶部出现具体原因与处理办法 |

## 6. 设置项

点击右上角齿轮，或点击顶部的 `A4 = 440.0 Hz` 进入设置。

| 设置 | 默认 | 范围 / 选项 | 说明 |
| --- | --- | --- | --- |
| A4 参考频率 | 440.0 Hz | 415–466 Hz | 改完后音名映射与曲线刻度立即更新 |
| 检测音域 | C2–C6 | 下拉选择，至少 6 个半音 | 范围外不显示音名 |
| 输入门限 | −60 dB | −70…−20 dB | 低于它判为“信号不足”；低声唱歌可继续往下调 |
| 置信度门限 | 75% | 50–95% | 低于它判为“低置信度”，曲线断开 |
| 平滑 | 轻 | 关闭 / 轻 / 中 | 轻 = 中值 3 + 30 ms 指数平滑 |
| 曲线时间窗 | 15 秒 | 10 / 15 / 30 秒 | 横轴显示最近多少秒 |
| 调试信息 | 关 | 开 / 关 | 显示采样率、窗口、Aperiodicity、削波比例等 |
| 音频来源 | 麦克风 | 麦克风 / 系统声音 | 系统声音需要共享屏幕并勾选分享音频 |
| 输入设备 | 默认设备 | 系统枚举 | 切换后自动重启音频链路；系统声音模式下不可选 |

设置保存在浏览器 `localStorage`（键名 `pitchScope.settings.v1`），换浏览器或清缓存会丢。旧版本保存的 −45 dB 默认门限会在首次加载时自动迁移为 −60 dB；之后你手动改回的值不会被再次覆盖。

目标音按钮：`无 / C4 / D4 / E4 / G4 / A4`。旁边的“试听”会播放 1.2 秒正弦音——**麦克风会拾取到它**，所以可以用来快速确认链路是否通。

### 7.3 整机验收步骤（需要麦克风 / 扬声器）

1. 启动服务，浏览器打开页面，点击“开始检测”，允许麦克风。
2. 播放 `a4.wav`：界面应稳定显示 **A4**，曲线落在 A4 附近；±5 cents 的标准音应基本贴着目标线。
3. 依次播放 `c4 / d4 / e4 / g4`：音名与八度应分别显示 C4 / D4 / E4 / G4。
4. 播放 `silence.wav` 或停止播放：应显示 **信号不足**，且不会持续误报音名，曲线断开。
5. 播放 `noise.wav`：应显示 **低置信度** 或 **信号不足**，不出现稳定音名。
6. 播放 `a4_quiet.wav`（≈ −52 dBFS）：默认 −60 dB 门限下应仍能显示 **A4**；如果显示“信号不足”，把设置里的门限调到 −65 或 −70。
7. 切到 **系统声音**：共享“整个屏幕”并勾选“分享系统音频”，用播放器循环播放 `a4.wav`，应显示 A4；停止共享后应回到“已停止”。
8. 对着麦克风唱一个稳定的“啊”：曲线应连续；故意唱偏低 / 偏高，应看到曲线整体下移 / 上移。
9. 设置里把 A4 改成 442 Hz：A4 的目标频率应变成 442.0 Hz，音名映射随之变化。
10. 界面中不应出现“得分 / 等级 / 命中率 / 练习报告 / 唱功评价”等字样。

## 9. 实现要点（给想改代码的人）

### 9.1 数据流

```
麦克风 / 系统声音
  → AudioWorklet (pitch-worklet.js)   独立音频线程
      环形缓冲 4096 samples，每 1024 samples 分析一次
      → PitchCore.createAnalyzer().analyze()      （YIN + 八度族选峰）
      → postMessage { t, f0, rawF0, aperiodicity, confidence, rms, db, ... }
  → 主线程 app.js
      → PitchCore.PitchTracker.track()   （门限判定 + 平滑 + 八度跳变确认 + 读数保持）
      → 音名 / 八度 / 音分 / 电平读数
      → Canvas 时间–音高曲线
```

判定逻辑全在 `PitchTracker` 里（纯计算），所以可以用真实录音在 Node 里逐帧回归，
不必每次都开浏览器；`app.js` 只负责把结果画出来。

### 9.2 关键参数

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 分析窗口 | 4096 samples | 48 kHz 下约 85.3 ms |
| 跳帧 | 1024 samples | 约 21.3 ms 更新一次 |
| 采样率 | 设备默认 | 通常 48 kHz |
| YIN 阈值 | 0.15 | 「干净凹陷」的绝对阈值 |
| 八度族归一容差 | 0.10 | 更短周期的凹陷只要不比已选凹陷深 0.10 以上，就判为同一周期族 |
| 八度族归一深度上限 | 0.30 | 整帧最深凹陷比它还浅才做归一（避免噪声帧被越拉越短） |
| 最大 Aperiodicity | 0.5 | worklet 内部硬上限 |
| 默认音域 | MIDI 36–84 | C2–C6，65.4–1046.5 Hz |
| 默认门限 | −60 dBFS | 低于它判为信号不足；可在 −70…−20 之间调 |
| 默认置信度 | 75% | 对应 Aperiodicity ≤ 0.25 |
| 跳变确认 | 2 帧 / 八度族 3 帧 | 八度族误判常只持续 1–2 帧；真实八度跳唱第 3 帧（≈64 ms）跟上 |
| 读数保持 | 150 ms | 单帧低置信度不清空平滑历史、读数不闪成 `—` |

### 9.3 为什么用 AudioWorklet

麦克风回调必须跑在音频线程，主线程画 Canvas 时不能阻塞采集。`pitch-worklet.js` 只做“组帧 + 调 YIN + 发消息”，所有 UI 与绘制留在主线程；`pitch-core.js` 不含 DOM / Web Audio 依赖，所以能在 Node 里直接单测。

### 9.4 音名映射

```
midiFloat = 69 + 12 * log2(f / A4)
midi      = round(midiFloat)
cents     = (midiFloat - midi) * 100
f_target  = A4 * 2^((midi - 69) / 12)
```

音名使用升号拼写（`C#4`、`F#4`…）；八度按 MIDI 惯例 `floor(midi/12) - 1`。

### 9.5 选峰为什么不是「第一个低于阈值」

经典 YIN 取 `[tauMin, tauMax]` 里第一个 `d'(τ) < 0.15` 的局部极小。真实人声在换字、
气声、尾音处基频凹陷会变浅（`d'(T) > 0.15`），而 `2T`、`3T` 处的凹陷反而更深，
规则就会整帧落到低一个 / 两个八度上——这正是 2026-11-18 记录的「八度族跳变」。

现在的规则（`YinAnalyzer._pickTau`，见 [`docs/ISSUE_OCTAVE_JUMP.md`](docs/ISSUE_OCTAVE_JUMP.md) §11）：

1. 先按经典规则取最短的「干净凹陷」（`d' ≤ 0.15`）——纯音、干净乐音行为不变；
2. 再沿倍数链 `τ/2`、`τ/3`、`τ/4` 往下归一：如果更短周期处也有凹陷，且不比已选的深
   0.10 以上（说明两处属于同一周期族），就换成更短的那个；
3. 真正含次谐波（气泡音 / 低八度伴唱）时，`2T` 的凹陷会远深于 `T`（例如 0.01 对 0.28），
   差距超过容差，因此不会被误改高；
4. 完全找不到可信凹陷时，如果解落在搜索下限附近（旧版会固定输出 63.49 Hz），直接判无效。

### 9.6 置信度、断线与读数保持

每一帧算出的 `confidence = 1 - aperiodicity`。低于设置门限时：

- 不往 `history` 里写点
- Canvas 折线在时间间隔 > 0.22 s 时自动断开
- 状态显示“低置信度”，而不是硬画一个错误音高

但**单帧**低置信度不再立刻清空（旧版会 `reset()` 平滑器，而 reset 后的第一帧会被无条件
接受，正好把一次八度误判画成尖峰）：读数保持 150 ms，超过才清空。低置信度期间曲线不新增
点，所以不会画出错误台阶。

## 10. 已知限制

1. **只支持单音 / 单声部。** 和弦、多人同时唱、强泛音的乐器会让 YIN 失去唯一周期，结果不可靠。
2. **气声、耳语、很弱的假声**可能被判为低置信度；这是设计目标，不是 bug。
3. **延迟是估算值。** 界面显示的“延迟约 82 ms”按 `窗口/2 + 跳帧 + 18 ms` 计算，实际还受系统音频栈、蓝牙耳机、浏览器缓冲影响；蓝牙耳机可能到 150 ms 以上。
4. **低频 C2 接近部分设备的拾音下限。** 笔记本内置麦对 65 Hz 的响应可能很弱，建议用耳机麦或 USB 麦。
5. **系统 / 驱动的降噪、回声消除、AGC 可能仍然生效。** 代码已请求关闭这些处理，但部分设备驱动不提供“原始”模式。
6. **不支持手机作为主要使用场景。** 页面可在移动浏览器打开，但 AudioWorklet 支持与麦克风权限策略因浏览器而异。
7. **不保存历史。** 刷新页面曲线清空；设置保留。
8. **`file://` 不可用。** 必须通过本地 HTTP 服务打开。
9. **Windows 麦克风独占。** 会议软件、录音软件占用麦克风时，浏览器可能报 `NotReadableError`。
10. **不做评分 / 报告。** 这不是功能缺口，是产品边界。
11. **系统声音依赖浏览器屏幕共享。** 必须共享“整个屏幕”并勾选“分享系统音频”；共享期间浏览器会显示共享指示。部分浏览器（如 Firefox）可能不提供系统音频选项。
12. **受保护的音频可能捕获不到。** DRM 视频、使用独占模式的应用、部分游戏可能不把音频放进系统回环；这不是算法问题。系统回环里同时有多个声源时，YIN 只能跟踪最强的单声部。
13. **当前交付仍以浏览器版为主。** “Windows 桌面客户端 + Android App”的最终形态在 `docs/ROADMAP.md` 中分阶段规划，当前阶段只做 Windows 侧。

## 11. 隐私

- `getUserMedia` 拿到的音频流只进入当前页面的 `AudioContext`。
- 系统声音模式使用 `getDisplayMedia`：只有音频轨进入 `AudioContext`；视频轨仅用于维持共享会话，代码不读取画面、不绘制、不上传，关闭检测即停止共享。
- 没有任何 `fetch` / `XMLHttpRequest` / WebSocket / 上传逻辑。
- 页面不加载 CDN、字体、统计脚本或图片。
- `localStorage` 只存设置（A4、音域、门限、目标音等），不存音频。
- 关闭页面即释放麦克风。

## 12. 故障排查

| 现象 | 原因 / 处理 |
| --- | --- |
| 页面提示“直接打开本地文件” | 用了 `file://`。改用 `start.bat` 或 `python tools\serve.py`。 |
| 点开始没反应 / 一直“连接中” | 检查浏览器是否弹了权限窗；看页面顶部红色提示条的具体错误。 |
| `NotAllowedError` | 麦克风权限被拒。按第 4 节重新允许。 |
| `NotFoundError` | 系统没有识别到输入设备。插拔麦克风，刷新页面。 |
| `NotReadableError` | 麦克风被其他程序占用。关闭会议 / 录音软件。 |
| 一直“信号不足” | 门限太高或麦克风增益太低。设置里把门限调到 −65 / −70 dB，或靠近麦克风。 |
| 系统声音模式提示“这次共享没有包含音频” | 共享时没有勾选音频。重新开始检测，选择“整个屏幕”并勾选“分享系统音频”。 |
| 系统声音模式没有弹出共享窗口 | 换 Chrome / Edge；检查系统是否禁止了屏幕共享，或浏览器版本过旧。 |
| 系统声音模式“输入设备”是灰的 | 正常现象。系统声音没有具体设备可选，显示“共享屏幕时选择”。 |
| 停止屏幕共享后界面停在“已停止” | 正常。重新点“开始检测”即可再次共享。 |
| 一直“低置信度” | 环境噪声大、唱得太轻或不是单音。换安静环境、唱稳一个音。 |
| 曲线不动 / “音频中断” | 设备被拔掉或驱动异常。重新选择输入设备。 |
| 端口被占用 | `serve.py` 会自动换端口；看终端打印的实际地址。 |
| 浏览器不支持 AudioWorklet | 换 Chrome / Edge 的较新版本。 |
| 改了 A4 但曲线没变 | 设置改完后会自动清空当前曲线并应用新映射；若仍在检测中，稍等一两帧。 |
